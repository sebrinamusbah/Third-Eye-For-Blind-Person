1. Introduction
The “Third Eye for the Blind” project is an assistive device designed to help visually impaired people detect obstacles in their path.
The system uses an ultrasonic sensor (HC-SR04) to measure the distance to obstacles and alerts the user through:
Sound → via speaker or buzzer
Tactile feedback → via DC vibration motor
Users can choose different modes:
Alarm only → sound alerts
Vibration only → motor alerts
Alarm + Vibration → both activate
The device can be worn like glasses, on shoes, or on a belt, making it flexible, hands-free, and easy to use. It provides real-time feedback, allowing the user to avoid obstacles safely.
Objective:
To detect obstacles and alert blind users immediately.
To provide multiple types of feedback for enhanced safety.
To make the system wearable and adaptable to different body parts.
